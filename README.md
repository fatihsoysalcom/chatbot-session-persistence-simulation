# Chatbot Session Persistence Simulation

This Python script simulates how a chatbot can maintain context across user interactions. It uses a simple JSON file to store and retrieve user-specific data, demonstrating the concept of post-chat persistence.

## Language

`python`

## How to Run

Run the script using: python chat_persistence.py
